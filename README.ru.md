## 🚂 О проекте

**rrt2-decomp** изучает исполняемый файл оригинальной _Railroad Tycoon II Platinum_ (PopTop Software, 1998–2001), чтобы понять каждое правило игры, а затем переписывает игру с нуля на Rust. Геймплей и двумерный изометрический («псевдо-3D») вид сохраняются, а все остальное модернизируется:

- 🖥️ **Любое разрешение**: 1080p, 1440p, 4K и сверхширокие экраны, с масштабируемым интерфейсом и поддержкой HiDPI. Интерфейс, текст и местность рисуются в родном разрешении, а оригинальные спрайты проходят этап качественного масштабирования (класса xBRZ или офлайн-модели ИИ), результат которого кэшируется при первом запуске.
- 🔍 **Плавный масштаб**, плавная прокрутка и поворот камеры.
- 🧮 **Точная детерминированная симуляция**: экономика, грузы, города, промышленность, фондовый рынок и ИИ, проверенные по оригинальной игре.
- 🛠️ **Удобство**: прокладка пути перетаскиванием с предварительным показом стоимости, отмена действий, карты спроса и прибыли, менеджер парка, автосохранение и переназначаемые клавиши.
- 🌎 **Моды и локализация**: игровые данные в удобочитаемых файлах, а также перевод на бразильский португальский.

> [!IMPORTANT]
> В этом проекте **нет ресурсов оригинальной игры**. Чтобы играть, нужна легальная копия _Railroad Tycoon II_ (например, издание Platinum из [GOG](https://www.gog.com/game/railroad_tycoon_2_platinum)). Клон читает данные из вашей установки по той же модели, что и [OpenRCT2](https://github.com/OpenRCT2/OpenRCT2) и [OpenTTD](https://github.com/OpenTTD/OpenTTD).

## 🔧 Сборка

Нужен стабильный Rust (версия закреплена в [`rust-toolchain.toml`](rust-toolchain.toml)). В Linux также нужны `clang` и `mold`, которые [`.cargo/config.toml`](.cargo/config.toml) использует как компоновщик.

```bash
git clone https://github.com/pedryvo/rrt2-decomp.git
cd rrt2-decomp
cargo build --release
```

Тесты, читающие данные оригинальной игры, запускаются, когда `RT2_DIR` указывает на вашу установку:

```bash
RT2_DIR=~/Games/railroad-tycoon-2 cargo nextest run
```

## 📦 Установка

1. Скачайте архив для своей системы на [странице Releases](https://github.com/pedryvo/rrt2-decomp/releases) (Linux x86_64 `.tar.gz`, Windows x86_64 `.zip`, macOS Apple Silicon или Intel `.tar.gz`). Каждый push в `main` также создаёт сборки для разработки: они лежат в артефактах запусков workflow "Release" на вкладке Actions.
2. Распакуйте куда угодно. В пакете только `rrt2` (шрифты и переводы встроены), документация и лицензии шрифтов. **Оригинальной игры в нём нет**: нужна ваша собственная копия Railroad Tycoon II (GOG, Steam или установка с CD).
3. При первом запуске укажите, где установлен оригинал. Путь сохраняется в `config.toml`:

```bash
./rrt2 set-path ~/Games/railroad-tycoon-2     # Windows: rrt2.exe set-path "C:\Games\Railroad Tycoon II"
./rrt2
```

`rrt2 --version` показывает версию и коммит git. Вместо `set-path` можно передать `--game-dir <папка>` или задать `RT2_DIR`.

| | Linux | Windows | macOS |
|---|---|---|---|
| Настройки и клавиши (`config.toml`) | `~/.config/rrt2` | `%APPDATA%\rrt2` | `~/Library/Application Support/rrt2` |
| Сохранения | `~/.local/share/rrt2/saves` | `%APPDATA%\rrt2\saves` | `~/Library/Application Support/rrt2/saves` |

`RRT2_CONFIG` и `RRT2_SAVES` переопределяют эти два места. Сборки для macOS и Windows создаются в CI, автор их пока не проверял.

## 🎮 Запуск игры (ранний предпросмотр)

```bash
cargo run --release -p rt2-game -- set-path ~/Games/railroad-tycoon-2   # once
cargo run --release -p rt2-game
```

Уже можно начать любой сценарий или кампанию с нуля, основать компанию, прокладывать пути, строить станции и вспомогательные здания, покупать поезда и задавать им маршруты, покупать предприятия и следить за газетами, финансами и биржей во время симуляции. Пока не хватает облигаций, торговли акциями и нескольких экранов (см. перечень в `docs/reference/screens.md`). Настройки и привязки клавиш хранятся в `~/.config/rrt2/config.toml`; сохранения — в `~/.local/share/rrt2/saves`.

## 🧰 Инструменты

Пока проект представляет собой набор инструментов для изучения. Игра появится позже.

```bash
# list a PK2 archive, naming the entries we know
cargo run --bin rt2-extract -- ~/Games/railroad-tycoon-2/data/RT2.PK2 -n re/names/exe_filenames.txt

# extract everything into a folder
cargo run --bin rt2-extract -- ~/Games/railroad-tycoon-2/data/RT2.PK2 -n re/names/exe_filenames.txt -o assets-extracted/rt2

# compute the hash of a filename
python3 re/scripts/pk2_hash.py setup.imb
```

## 🗂️ Структура

```
crates/
  rt2-formats/   pure parsers for the game's file formats (PK2, LNG, …)
  rt2-sim/       deterministic simulation core (no I/O, no rendering)
  rt2-render/    wgpu terrain renderer (mesh, isometric camera; no game logic)
  rt2-viewer/    `rt2-viewer <map>`: window or `--screenshot` PNG
  rt2-oracle/    differential-test harness (original EXE in Unicorn)
  rt2-tools/     inspection and extraction CLIs
docs/
  PLAN.md        development plan
  formats/       one spec per file format
  spec/          one spec per game subsystem
  reference/     rules extracted from the manual and strategy guide
re/
  symbols.toml   functions and globals identified in the executable (source of truth)
  names/         recovered filenames
  scripts/       reverse-engineering helper scripts
```

## 🔬 Методология

1. **Опорные точки**: строки, импорты и таблицы данных в исполняемом файле показывают, где находится каждая подсистема.
2. **Полная классификация, точечная декомпиляция**: каждая функция классифицируется (библиотека, платформа, отрисовка, интерфейс или симуляция), и мы продвигаемся от опорных точек наружу, подсистема за подсистемой. Код библиотек (CRT, Miles, Smacker, DirectX) откладывается в сторону на раннем этапе, а для каждой функции симуляции пишется спецификация.
3. **Сначала спецификация, потом код**: правила описываются в [`docs/spec/`](docs/spec/) с псевдокодом, константами и адресом источника каждого из них. Код на Rust пишется по спецификациям, а не по ассемблеру.
4. **Эталон — исполняемый файл, а не руководство**: описывается каждая функция симуляции, а покрытие отслеживается публично. Формулы доказываются равными путем запуска оригинальных функций в x86-эмуляторе против нашего кода на Rust, а поведение всей игры проверяется продвижением одного и того же сохранения в оригинале (под Wine) и в клоне с сравнением результатов.

Анализ выполняется в [Ghidra](https://ghidra-sre.org/) через MCP-сервер **REA**. Работа разделена между специализированными ИИ-агентами ([`.claude/agents/`](.claude/agents/)), каждый из которых использует модель, лучше всего подходящую для его задачи.

Документация проекта в `docs/` написана на португальском.

## ⚖️ Правовая информация

_Railroad Tycoon_ — товарный знак соответствующих правообладателей. Это некоммерческий фанатский проект, не связанный с PopTop Software, Take-Two Interactive или каким-либо правообладателем. Оригинальный код и ресурсы здесь не распространяются. В репозитории хранится только новый код, документация, созданная обратной разработкой для обеспечения совместимости, и имена файлов, необходимые для чтения данных из легальной копии.
