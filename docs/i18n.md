O jogo original traz só inglês (`default2.lng`, 2807 ids). O clone carrega o inglês da instalação do usuário e sobrepõe traduções versionadas aqui, por id.

## Formato (`assets/lang/<locale>.toml`, UTF-8)

```toml
[meta]
locale = "pt-BR"
language = "Português (Brasil)"
source = "default2.lng do Railroad Tycoon II Platinum, 2807 ids"

[strings]
7 = "Erro ao abrir o arquivo '%1'"
812 = "passageiros"
```

- Chave = id numérico do `default2.lng` (a última definição vence, ver `docs/formats/lng.md`). Todo id deve estar presente.
- Escapes TOML normais: uma quebra de linha do original (`\n` no `.lng`) vira `\n` na string TOML.
- **Preservar exatamente**: os marcadores `%1`…`%9` (podem mudar de ordem na frase, mas cada um aparece o mesmo número de vezes), a quantidade de `\n`, espaços no início e no fim, e símbolos como `$`.
- **Não traduzir** nomes de arquivo (`SH240%1.PCX`, `SH080%1.PCX`), os códigos de trapaça (ids 2722–2737, que o jogador digita) nem textos que sejam só pontuação ou números: copie igual.
- Tabelas com limite de tamanho, como `CARGO_TYPES_SHORT` ("max 5 characters", ver os comentários `;t...` no `.lng`): respeite o limite.
- Nomes próprios históricos (ferrovias, pessoas, cidades) ficam na forma usual do idioma (por exemplo "Nova York", "Нью-Йорк", "纽约"); nomes de locomotivas não são traduzidos.
- Terminologia consistente dentro de cada idioma: cada arquivo tem uma seção `[glossary]` opcional com os termos escolhidos (`"stock" = "ações"`), que não é lida pelo jogo.

## Verificação

`python3 -I scripts/check-translations.py [--lng <default2.lng>]` confere todos os arquivos: ids completos, marcadores e quebras de linha preservados, nomes de arquivo intactos e limites de tamanho. O padrão do `--lng` é `$RT2_DIR/default2.lng`.

## Textos do clone (`[app]`)

O clone tem textos que não existem no `default2.lng` (botões "Menu"/"Save", títulos das telas de mercado, estações e indústrias, dicas, avisos, rótulos de colunas). Eles ficam numa tabela própria, `crates/rt2-game/src/app_strings.rs`, com o inglês no código e ids fora da faixa do LNG: **`100000 + posição`**. A lista é só de acréscimo (um id nunca é reutilizado nem reordenado). `%1`..`%9` são argumentos, como no LNG; a ordem pode mudar na frase (`"%2 de %1 de %3"`).

Cada arquivo de idioma traduz esses textos numa tabela separada:

```toml
[app]
100000 = "Menu"
100001 = "Salvar"
```

Ids ausentes ficam em inglês (com uma linha de log na troca de idioma). O texto 100007 (`%1 %2, %3`) é o formato da data: `%1` mês (nome completo), `%2` dia, `%3` ano e `%4` mês abreviado (ids 1426+, "Jan"; `1月` em chinês). Só o zh-CN usa `%4` (`%3年%4%2日` → "1876年1月12日"); os demais idiomas ficam com `%1`.

## Carregamento e distribuição

* `rt2-formats::i18n` lê o TOML (`Translation`) e `Lng::overlay` troca por id as strings do inglês da instalação; o que o idioma não traduz fica em inglês.
* Os arquivos de `assets/lang/*.toml` são **embutidos no executável** na compilação (`crates/rt2-game/build.rs` gera a lista de `include_str!`; uma pasta vazia ou ausente dá uma lista vazia). Um binário só carrega todos os idiomas, sem pasta de dados para distribuir.
* Para testar ou acrescentar um idioma sem recompilar, uma pasta de `*.toml` substitui (por `locale`) os embutidos: `$RRT2_LANG_DIR`, ou `lang/` ao lado do executável.
* Idioma: `language = "pt-BR"` no `config.toml`; ausente = locale do sistema (`LC_ALL`, `LC_MESSAGES`, `LANG`), senão inglês. O mesmo idioma primário serve (`pt-PT` usa `pt-BR`). `--language` / `$RRT2_LANG` valem só para a execução. No menu principal há um botão por idioma com o nome nativo (`[meta].language`); clicar troca na hora (todo o layout é refeito) e grava no `config.toml`.

## Fontes

Cinzel (a fonte que imita a Copperplate), Anton e Dancing Script não têm cirílico, e nada tem CJK. Para `ru` e `zh-CN`, o `rt2-ui` usa fontes vendorizadas com cobertura própria (Cormorant SC, Oswald, Marck Script, Noto Sans SC; ver "Idiomas e fontes" em `docs/ui.md`).
