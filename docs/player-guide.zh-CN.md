欢迎阅读 **rrt2-decomp** 玩家指南！本项目是 1998 年经典策略经营游戏《铁路大亨II：白金版》（*Railroad Tycoon II Platinum*）的现代化开源重实现版本，使用 Rust 语言从零编写。本指南将为您全面介绍游戏安装与运行配置、核心玩法与铁路运营、常用操作快捷键、与 1998 原版的技术演进差异以及可选的现代增强功能。

> [!IMPORTANT]
> **rrt2-decomp 不包含任何原版游戏的专有受版权保护资源**。运行本游戏前，您必须拥有一份合法的《铁路大亨II：白金版》游戏资产（如来自 [GOG](https://www.gog.com/game/railroad_tycoon_2_platinum)、Steam 或正版安装光盘）。重制引擎将以只读方式直接从您的原有游戏目录中读取图像数据包、音频、地图及文本，这与 OpenRCT2 和 OpenTTD 的设计模式完全一致。

## 1. 安装与运行

### 系统要求与核心文件

运行 `rrt2` 需满足以下基础环境：
- **操作系统**：Linux (x86_64)、Windows 10/11 (x86_64) 或 macOS 11+（Apple Silicon 芯片或 Intel x86_64）。
- **显卡/图形驱动**：支持 Vulkan、DirectX 12 或 Metal（由 `wgpu` 驱动）。
- **原版游戏数据**：合法的《铁路大亨II：白金版》文件，必须包含：
  - `data/RT2.PK2`：主素材包（地形贴图、精灵图与界面组件）。
  - `RT2_PLAT.EXE`：原版执行文件（用于提取机车参数、产业配平表等核心数据）。
  - `default2.lng`：语言文本数据表。
  - 可选目录：`maps/`（官方剧本地图）、`games/`（预制存档）和 `anim/`（`.SMK` 格式过场动画动画，系统需预装 `ffmpeg` 与 `ffplay`）。

### 自动扫描检测游戏目录

在首次启动时，`rrt2` 会自动弹出**游戏路径引导设置界面**。程序会按照确定性顺序自动扫描常见路径：
- **Steam 库**：Steam 游戏库文件夹（`steamapps/common/Railroad Tycoon 2`），包括 Steam Flatpak 路径与 Proton 前缀环境（`compatdata/284840/pfx/drive_c`）。
- **GOG**：Windows 注册表项（`HKLM\SOFTWARE\WOW6432Node\GOG.com\Games`）、标准 `GOG Games/Railroad Tycoon II` 文件夹及 Heroic 启动器目录。
- **Lutris 与 Wine**：已配置的 Lutris 容器（`games/*.yml`）、标准 Wine 目录（`~/.wine`）、Bottles 及 PlayOnLinux。
- **Windows 标准驱动器目录**：在各盘符（`A:` 至 `Z:`）下的 `C:\Games\` 和 `C:\Program Files (x86)\`。

检测到可用安装后，列表中将列出各个来源（如 "Steam"、"GOG"、"Wine prefix"）。选中对应的路径后点击**开始游戏**（Play）即可。

### 手动指定游戏路径

如果您的游戏存放在自定义路径下，可通过以下方式之一进行配置：
1. **界面图形化选择**：在设置界面点击**选择文件夹...**，调出操作系统原生文件选择器（Linux 下利用 XDG Desktop Portal，完全支持 Flatpak 沙盒）。
2. **命令行命令设置**：
   ```bash
   ./rrt2 set-path ~/Games/railroad-tycoon-2
   # Windows 环境：
   rrt2.exe set-path "C:\Games\Railroad Tycoon II"
   ```
3. **命令行参数或环境变量**：
   ```bash
   ./rrt2 --game-dir /path/to/game
   # 或通过环境变量：
   export RT2_DIR=/path/to/game
   ./rrt2
   ```

### 各操作系统发行包

- **Linux**：
  - **AppImage**：单文件自包含可执行包，内置全套矢量字体与翻译数据。赋予执行权限（`chmod +x rrt2-*.AppImage`）后可直接运行。
  - **Flatpak**：应用 ID 为 `io.github.pedryvo.rrt2.flatpak`。在沙盒隔离环境中运行；初次启动通过文件弹窗授权访问原版游戏文件夹。
  - **压缩包（`.tar.gz`）**：解压后直接执行 `./rrt2`。系统仅需动态依赖 `glibc` 与 `libasound.so.2`。
- **Windows**：
  - **Inno Setup 安装版（`-setup.exe`）**：无需管理员提权，自动添加开始菜单快捷方式，支持从 Windows 设置中完全卸载，并可自动记录资产路径。
  - **winget**：通过 Windows 程序包管理器一键安装：
    ```cmd
    winget install pedryvo.rrt2
    ```
  - **便携版 ZIP**：解压至任意目录，双击运行 `rrt2.exe`。
- **macOS**：
  - **磁盘映像（`.dmg`）**：双击挂载 `.dmg`，将 `RRT2.app` 拖入 `/Applications` 应用程序文件夹。原生支持 Apple Silicon（`aarch64`）和 Intel（`x86_64`）。
  - *Gatekeeper 安全提示*：因开源构建包未经商业签名，首次打开如提示无法验证，可在 Finder 中右键点击 `RRT2.app` 选择**打开**，或在终端执行：
    ```bash
    xattr -dr com.apple.quarantine /Applications/RRT2.app
    ```

### 配置文件与存档路径

本引擎严格坚持不篡改原版安装目录的原则。所有用户数据均妥善保存在系统标准目录中：

| 类别 / 作用 | Linux | Windows | macOS |
|---|---|---|---|
| 用户设置文件 (`config.toml`) | `~/.config/rrt2/` | `%APPDATA%\rrt2\` | `~/Library/Application Support/rrt2/` |
| 游戏存档 (`*.GAM`, `*.toml`, `*.png`) | `~/.local/share/rrt2/saves/` | `%APPDATA%\rrt2\saves\` | `~/Library/Application Support/rrt2/saves/` |
| 导出财务报表 (`*.csv`) | `~/.local/share/rrt2/reports/` | `%APPDATA%\rrt2\reports\` | `~/Library/Application Support/rrt2/reports/` |
| 历史最高分记录 (`hiscore.dat`) | `~/.local/share/rrt2/` | `%APPDATA%\rrt2\` | `~/Library/Application Support/rrt2/` |

> [!TIP]
> 开发者和高级玩家可通过环境变量 `RRT2_CONFIG`、`RRT2_SAVES` 及 `RRT2_REPORTS` 自定义覆盖以上路径。

## 2. 新手入门指南

### 游戏模式：历史战役、独立剧本与沙盒

在主菜单选择**单人游戏（Single Player）**开始征程：
- **经典原版战役（Original Campaign）**：体验 18 个见证世界铁路发展史的经典剧本，从早期美国先驱（如著名的*巴尔的摩与俄亥俄铁路 B&O*）到横贯欧洲大陆与全球扩张。每个剧本开局可自选一项关键奖励（如更低的贷款利率、桥梁施工补贴或机车折扣）。
- **世纪之交战役（The Second Century）**：体验资料片中针对 20 世纪及 21 世纪设计的 18 个高难度现代化剧本，包含电气化机车、高速客运网络、大规模工业物流及二战后经济转型。
- **独立剧本（Single Scenario）**：直接加载任意 `.MAP` 或 `.MP2` 地图。阅读任务简报、确认胜负条件（铜牌、银牌、金牌目标），自由设定工业与金融难度。
- **沙盒模式（Sandbox Mode）**：自由铺设线路，不受破产清算、偿债压力或竞争对手恶意收购的限制。
- **教程与示例剧本**：推荐新手首先加载 Tutorial 地图，快速掌握铺轨、设站和排班的基础要领。

### 创建铁路公司

在无默认公司的剧本中，您将首先进入创办公司（Start New Company）界面：
1. **公司名称与标识**：输入公司名称（最多 30 个字符），挑选专属徽章图标及公司标识色。
2. **初始资本与股权分配**：拖动滑块设定初始股本规模。实时预览界面会显示：
   - 注入公司金库的运营启动现金。
   - 首次公开发行的股份总数与开盘股价。
   - 董事长个人出资额（"You buy"）：由您个人出资持有的原始股权比例。
3. **保住董事长席位**：请保持公司健康盈利！若公司持续亏损或您个人抛售了过多股票，董事会和敌对大股东可在股东大会上发起投票罢免您的职位。

### 铺设铁轨

铁路线路是帝国的命脉：
1. 在左侧工具栏点击**铺设铁轨（Lay Track）**工具。
2. 在地图起点格**按住鼠标左键**，朝目的地平稳拖动。
3. **实时寻路与建造成本预览**：拖动过程中，系统会自动规划最优路径、测算跨河桥梁造价、计算坡度梯度，并实时计算精确工程款。若路线呈现红色，说明遭遇地形阻挡（如坡度过陡或未取得路权）。
4. 松开鼠标左键，立即确认施工并扣除资金。
5. 在拖动过程中按 `Esc` 键可直接取消操作，不消耗分毫资金。

> [!TIP]
> 尽量将线路坡度控制在 2% 以下。3% 至 6% 的陡坡会导致蒸汽机车急剧减速，并大幅增加燃料消耗与机械磨损。

### 兴建车站与配套设施

车站用于聚拢周边城镇居民与工厂物资：
1. 点击工具栏的**建造车站（Build Station）**。
2. **车站规格等级**：
   - **小型车库（Small）**：造价低（基础 $50K），辐射半径 2 格。适合偏远乡村的原材工厂。
   - **中型车站（Medium）**：造价适中（基础 $100K），辐射半径 4 格。适用于蓬勃发展的新兴城镇。
   - **大型终点站（Large）**：造价高昂（基础 $200K），辐射半径 8 格。大型都市枢纽的首选。
3. **金色覆盖光圈与幽灵指示**：光标在地图悬停时，**金色光圈**直观标明物资吸纳半径，建筑物轮廓同步反馈：
   - **绿色**：平整可用、允许修建。
   - **黄色**：已紧邻现有轨道、允许直接连结。
   - **红色**：无效位置（地势过陡、深水区或与其它车站范围冲突）。
4. **建筑风格定制**：可自由切换维多利亚式、殖民地式、传教所式、都铎式或京都式风格。
5. **升级附属建筑**：点击已建成的车站，可添购高收益设施：
   - **运行保障**：*水塔*（Water Tower）与*沙房*（Sandhouse）缩短蒸汽机车补给时间；*机车转车盘/扇形机房*（Roundhouse）降低 50% 的列车日常维护费用。
   - **商业设施**：*电报局*（Telegraph）加速运费结算；*酒店*（Hotel）与*餐馆*（Restaurant）大幅提升客运衍生收益；*海关*（Customs House）增加跨国货运收益。
   - **仓储物流**：*谷物仓*、*冷库*与*货物棚架*避免货物滞留腐败，锁定供求差价。

### 选购机车

点击任意车站或打开机车总览界面，点击**购买列车（Purchase Train）**：
- **机车目录**：按历史时期分类展现蒸汽、柴油和电力机车。
- **性能矩阵图**：核心参数包含坡度速度矩阵（分析在 0%、2%、4%、6% 坡度下拉动 1 至 6 节车厢的极限时速）。
- **综合成本考量**：下单前务必综合衡量年均保养成本、燃料类型与消耗率、机车可靠度及起步加速度。
- **线路电气化**：注意，电力机车必须在已架设接触网的电气化铁路上方可运行！

### 编组车厢与规划行车线路

1. **站点排班**：在列车调度面板中，点击地图或站点列表添加停靠站。
2. **挂载车厢**：
   - **特快货运**：旅客与邮件（运费单价高，极为看重运行速度与时效性）。
   - **大宗工业物资**：煤炭、铁矿、小麦、牲畜、原木、石油、钢材、工业制成品、汽车等。
3. **装车策略**：设定列车进站后是立即发车、半满发车还是必须等待满载（`Wait for Full Cargo`）。

### 财务运作与股票交易

一位卓越的铁路大亨必须具备敏锐的资本运作头脑：
- **企业债券（Bonds）**：发行债券筹措资金修建干线。利率直接挂钩您的公司信用评级（从 AAA 级直至垃圾级 F）。现金流稳定后应尽快偿还以减少利息开支。
- **股票市场（`M`）**：
  - **买卖股票**：动用个人积蓄增持本公司股票以巩固控制权；或在低位买入竞争对手股票以分享其丰厚股息。
  - **公司回购（Share Buybacks）**：动用公司资金在公开市场回购自家股票，能有效提升每股收益（EPS）并刺激股价飙升。
  - **股票拆细（Stock Splits）**：当每股单价过高时，系统将自动执行 1 拆 2 拆股，提高股票流动性。
- **派发现金股利**：按年向股东派发现金红利，能极大提振投资者信心并拉升股价，但注意留足公司周转现金。
- **兼并与恶意收购**：当您个人或公司合计吃下某对手公司超过 50% 的流通股时，即可触发强制收购，将其旗下全部铁路、车站及车队收入囊中。

## 3. 按键操作与快捷键

所有键位均可在**设置选项（`F10`） > 按键**中自由重映射。

### 视角移动与平滑缩放

| 动作 | 默认按键 / 输入 | 说明 |
|---|---|---|
| 移动地图视角 | `W`, `A`, `S`, `D` 或 方向键 | 平滑平移地图 |
| 鼠标拖拽平移 | 按住鼠标右键并拖动 | 最自然的等轴视角拖动 |
| 屏幕边缘滚屏 | 鼠标靠近屏幕边缘 4 像素内 | 可在游戏性设置中开启/关闭 |
| 逆时针旋转视角 | `Q` | 等轴视角逆时针旋转 90 度 |
| 顺时针旋转视角 | `E` | 等轴视角顺时针旋转 90 度 |
| 放大画面 | 滚轮向上 / `+` / 小键盘 `+` | 连续无级平滑缩放 |
| 缩小画面 | 滚轮向下 / `-` / 小键盘 `-` | 连续无级平滑缩放 |
| 重置视角居中 | `Home` | 回到地图中央或预设视点 |

### 时间流速与暂停控制

| 动作 | 快捷键 | 说明 |
|---|---|---|
| 暂停 / 恢复 | `Pause` 或 `Space`（空格） | 冻结游戏模拟时钟 |
| 减慢时间流速 | `-` 或 小键盘 `-` | 降低游戏模拟流速 |
| 加快时间流速 | `+` 或 小键盘 `+` | 提高游戏模拟流速 |
| 切换全屏显示 | `F11` | 在窗口化与无边框全屏间切换 |
| 调整界面缩放 | `Ctrl +` / `Ctrl -` | 以 25% 为步进调节 UI 大小（100% 至 300%） |
| 静音控制 | `Ctrl + M` | 开启或关闭音乐与音效 |
| 切换下一首曲目 | `Ctrl + N` | 播放原声音乐列表中的下一首 |

### 信息面板与快速查询

| 窗口 | 按键 | 显示内容 |

### 财务报表与交互式图表

在公司账册中点击 **Reports** 按钮（或按键 `1`、`2`、`3`）：
- **交互式趋势图（标签页 1）**：可在时间线上同时比对 12 项财务指标：总营收、总支出、净利润、现金储备、总负债、净资产、股票价格、每股净资产、每股收益与每股股息。图表采用色盲友好的 Okabe-Ito 配色，支持鼠标悬停回溯查看历史某年某月的数值。
- **分类损益表（标签页 2）**：横向对比 13 个收支分类项目，查看终生累计、本年度至今及过去 5 个财年的明细数字。
- **运营排行榜（标签页 3）**：实时对盈利最强的列车与吞吐量最高的枢纽车站进行排序。点击任意一行，镜头即可自动对焦至对应列车或车站。
- **导出 CSV**：在任意报表页点击 **Export CSV**，数据将以标准电子表格格式导出至 `~/.local/share/rrt2/reports/*.csv`，方便玩家在 Excel 等软件中做深度经济分析。

## 4. 相比 1998 原版的改进

在完整传承《铁路大亨II：白金版》标志性玩法、音乐氛围与美术风格的基础上，`rrt2-decomp` 实现了现代工程技术的全面跃升：

```
┌─────────────────────────┬─────────────────────────────────┬─────────────────────────────────┐
│ 特性对比                 │ 1998 原版游戏（PopTop）          │ rrt2-decomp（现代 Rust 重制版） │
├─────────────────────────┼─────────────────────────────────┼─────────────────────────────────┤
│ 屏幕分辨率               │ 锁定 800x600 或 1024x768        │ 原生支持 1080p、1440p、4K 及带鱼│
│ 界面缩放                 │ 不支持（高分屏下图标文字极小）  │ 矢量字体渲染（100% 至 300% 缩放)│
│ 仿真还原精度             │ 闭源 Win32 x86 二进制执行文件   │ 100% 逐位还原的原版确定性仿真   │
│ 图形渲染底层             │ DirectDraw / 软解 GDI 渲染      │ 现代硬件加速管线（wgpu）        │
│ 摄像机视角操作           │ 档位缩放、平移卡顿              │ 无级平滑缩放、自由平滑拖拽      │
│ 多人联网支持             │ DirectPlay 4、IPX、调制解调器   │ 现代 TCP/IP 锁步网络协议        │
│ 联机容错机制             │ 主机掉线整盘崩溃；不支持中途加入│ 自动主机迁移、中途重连恢复      │
│ 支持操作系统             │ 仅 Windows 95/98/XP             │ 原生运行于 Linux、Windows、macOS│
│ 语言支持                 │ 锁光盘版本（单语言）            │ 六国语言游戏内免重启即时切换    │
└─────────────────────────┴─────────────────────────────────┴─────────────────────────────────┘
```

### 100% 逐位还原的确定性仿真

仿真核心引擎（`rt2-sim`）杜绝模糊猜测与粗略近似。机车制动减速物理模型、故障概率分布、都市货运繁衍、股价算法公式乃至竞争对手 AI 的博弈树，均通过逆向工程反编译并由 Unicorn 仿真器与原版程序进行了差分对照测试（Differential Testing）。加载原版存档后，每一天演化的字段数值均与原版完全吻合。

### 原生高分辨率、带鱼屏与 4K 支持

彻底告别旧时代低分辨率强制拉伸模糊。由 `wgpu` 驱动的现代渲染架构以您显示器的物理分辨率直接光栅化三维地形网格、河流与铁轨。原版 2D 精灵图则通过高质量重采样与矢量平滑滤镜（xBRZ 算法），在首次运行完成计算并持久缓存在本地，于 4K 甚至 32:9 超宽带鱼屏上呈现令人惊叹的通透细节。

### 矢量文字排版与 HiDPI 界面缩放

摒弃了原版边缘模糊的粗糙点阵位图字模，`rrt2-decomp` 精心配套了开源 SIL OFL 授权的现代矢量字体家族：
- **Cinzel**：复古雕刻衬线字体，优雅还原原版 Copperplate 气质。
- **Libre Franklin**：清晰直观的无衬线字体，用于数据表格与操作按键。
- **Dancing Script**：复古行书，还原当年的褒奖证书与优胜信函。
- **Anton & Oswald**：沉稳厚重的经典标题用字。
- **Noto Sans SC（思源黑体精简集）**：专为简体中文深度适配的无衬线字库，完美覆盖 GB2312 常用汉字，彻底解决跨平台缺字乱码。
- **Cormorant SC**：为俄语本地化提供纯正的西里尔字母支持。

界面缩放支持在 100% 至 300% 范围内任意调节。

### 现代化 TCP/IP 锁步多人网络对战

原版早已被现代系统淘汰的 DirectPlay 4、局域网 IPX 与电话拨号代码被完全重构为现代高效的跨平台 TCP/IP 锁步网络协议：
- **主机定序锁步网络（Lockstep）**：玩家间仅交换极小体积的指令数据包，保障所有客户端严格以相同的游戏分钟推进推演。
- **断线重连与中途加入（Join in Progress）**：掉线玩家可重新连入正在激战的局域网或公网对局，主机自动打包发送当前世界内存快照。
- **自动化主机迁移（Host Migration）**：房主意外断网退出时，网络层自动选举 ID 最小的在线客户端平滑接管主机职责，对局不会终止。
- **断线 AI 托管机制**：若有玩家弃赛离开，该名下铁路帝国立即交由高水平电脑 AI 接续托管，避免全网经济断层。

### 内置六国语言即时切换

您可随时在**设置 > 语言**菜单中于 **English**、**Português**、**Español**、**Deutsch**、**中文（简体中文）**与 **Русский** 之间自由切换。整套界面、剧本简报与字号度量体系瞬间重算刷新，无需保存重启游戏。

## 5. 可选现代增强功能

所有现代生活质量（QoL）功能均采用模块化设计，默认状态下百分之百遵循原版纯正逻辑。

### 基于规则的原版缺陷修复（`Fix`）

1998 原版中存在若干广为人知的遗留逻辑缺陷（如创办人出资购股时的取整偏离、车站部分升级项目的重复计费、长周期推演下金库现金整数溢出等）。在 `rrt2-decomp` 中您可以自主决策：
- **严苛还原模式（默认）**：保留原版一切奇特表现，满足最严谨的怀旧考古与旧录像复盘验证。
- **现代配平修复模式（`Fix`）**：启用经数学验证的代码缺陷修复逻辑，所有修正策略均随规则标记写入存档，确保多人与回放的完全自洽。

### 施工一键撤销（`Ctrl+Z`）

铺设昂贵的越洋悬索桥时不慎点歪了地格？只需按下 `Ctrl + Z`，即可立刻撤销最近一次轨道铺设或站房建造动作。只要新线路上尚未有运行中的列车驶过，耗费的建造成本将全额退还。

### 车队管理器与机车批量换代

当您的铁路网络延伸至上百列机车时，无需再逐个点开窗口繁琐换车：
- **车厢编组模板（Consist Templates）**：预设保存常用的车厢搭配（如“豪华快速客车”或“双机重载煤矿特快”），在购买新车时一键套用。
- **全车队批量升级替换**：指定退役某一老旧型号机车，系统将在受影响车次下一次进站检修时自动为其更换为新型牵引动力。

### 高级数据可视化地图图层

超越原版的物资分布图，带来更具深度的决策视角：
- **全图供求热力图**：直观高亮原产地丰饶富余的货源及处于物资饥渴状态的工业重镇。
- **线路坡度色阶图**：彩色标记山区爬坡瓶颈，辅助选线降坡。
- **区间盈利分析图**：直观揭示名下盈利丰厚的黄金干线与长期亏损的支线死链。
- **运力拥堵与瓶颈图**：警示因单线交会或调度不力引发严重候车滞留的咽喉路段。

### TOML 数据格式模组支持（Modding）

游戏核心属性已与底层二进制彻底解耦：
- 机车参数、车厢自重与载重、货运关系树、工厂转化比例以及剧本条件均支持导出并读取人类友好的 **TOML** 文件。
- 模组创作者可自由引入全新的地方机车、设计独特的复合产业链或自定战役挑战，无须重新编译 Rust 源代码。

### 无障碍辅助功能

- **色盲辅助色彩方案**：全系报表曲线与雷达小地图采用权威的 Okabe-Ito 色盲安全配色，辅以独特的点划线型与几何符号（圆点、方块、三角、菱形）。
- **独立字号调节**：支持在不改变 HUD 面板比例的前提下，单独特大文字排版字号。
- **视觉化音效字幕指示**：为听障玩家提供屏幕边缘动态图标警示，直观提示机车严重故障、遭遇列车强盗、脱轨抢险及财务警戒通知。
